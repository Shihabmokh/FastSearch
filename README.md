# FastFind — بحث فوري في كل ملفات الهاتف (أندرويد)

مثل Everything على الويندوز، لكن للهاتف، ويبحث أيضًا **داخل** الملفات.

## كيف يعمل
1. **فهرسة الأسماء (ثوانٍ):** يمشي على كل المجلدات (الذاكرة الداخلية + بطاقة SD) بـ `Files.walkFileTree`
   ويخزّن الاسم/المسار/الحجم/التاريخ في SQLite. إعادة الفحص تزايدية: يقارن بصمة (حجم+تاريخ) في الذاكرة
   فلا يلمس قاعدة البيانات إلا للملفات الجديدة/المتغيرة/المحذوفة.
2. **فهرسة المحتوى (في الخلفية):** يقرأ النصوص والأكواد وCSV/JSON/HTML وDOCX/XLSX/PPTX/ODT وPDF
   ويضعها في فهرس FTS4 (بحث نصي كامل مع مطابقة بادئات). يكمل من حيث توقف إن أُغلق التطبيق.
3. **البحث:** فوري أثناء الكتابة، ترتيب بالصلة (مطابق تمامًا ← يبدأ بالكلمة ← يحتويها) ثم الأحدث.

## مزايا إضافية عن Everything
- بحث داخل المحتوى مع مقتطف مظلّل.
- عربي ذكي: يتجاهل التشكيل والتطويل ويوحّد أ/إ/آ/ا وى/ي وة/ه والأرقام الهندية؛ والصينية تعمل أيضًا.
- بحث تقريبي تلقائي عند عدم وجود نتيجة (rprt ← report).
- ملفات ذات امتداد غير معروف: يتم الكشف عن النص تلقائيًا؛ ملفات cp1256 العربية القديمة تُقرأ صحيحًا.

## صيغة البحث
```
تقرير 2026             كل الكلمات يجب أن تظهر
"عبارة دقيقة"  -كلمة    عبارة / استبعاد
ext:pdf   ext:jpg;png   type:image|video|audio|doc|sheet|slide|archive|apk|code
size:>10mb   size:1mb..5mb
modified:today|yesterday|week|month|year   modified:7d   after:2026-01-01   before:2026-06-30
path:Download   is:folder   is:file
c:كلمة                  بحث داخل المحتوى
re:^IMG_\d+             تعبير نمطي على الاسم
```
الأزرار أسفل مربع البحث: **الأسماء / المحتوى / الكل**. اضغط مطولًا على أي نتيجة للمشاركة أو نسخ المسار.

## بناء ملف APK

### الطريقة 1 — GitHub Actions (بدون تثبيت شيء)
1. أنشئ مستودعًا جديدًا على GitHub وارفع محتوى هذا المجلد كما هو.
2. تبويب **Actions** ← *Build APK* ← **Run workflow**.
3. بعد دقائق نزّل `FastFind-debug-apk` من قسم Artifacts، فك الضغط، وثبّت `app-debug.apk`.

### الطريقة 2 — Android Studio
`File ▸ Open` على هذا المجلد ← انتظر Sync ← `Build ▸ Build APK(s)`.
(يحتاج JDK 17 وAndroid SDK 34.)

## على الهاتف
- فعّل «التثبيت من مصادر غير معروفة» لتطبيق المتصفح/الملفات، وقد يعرض Play Protect تحذيرًا لأن التوقيع تجريبي (debug).
- عند أول فتح امنح إذن **الوصول إلى جميع الملفات**. اترك التطبيق مفتوحًا أثناء الفهرسة الأولى (الشاشة تبقى مضاءة أثناءها).
- الفهرس محلي بالكامل ولا يُرسل أي شيء خارج الجهاز.

## حدود معروفة
- لا يقرأ مجلدات `Android/data` و`Android/obb` (أندرويد 11+ يمنعها).
- صيغ Office القديمة (doc/xls/ppt) وPDF الممسوح ضوئيًا (صور) غير مدعومة للمحتوى بعد (الأسماء تعمل).
- لا يتحدّث الفهرس لحظيًا؛ يعيد الفحص عند فتح التطبيق إذا مرّ أكثر من 10 دقائق، أو يدويًا من القائمة ⋮.
